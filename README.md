> This repository contains the essential materials for reproducing the results of **SpatialCOC**.

## 💡Description

SpatialCOC is a integrative framework for spatial multi-omics data. SpatialCOC treats different omics modalities as continuous functions defined by their shared spatial coordinates, enabling it to uncover nonlinear correlations among these modalities.

![SpatialCOC_Framework](./Figures/SpatialCOC_Framework.png)

## 🎬Getting started

Please follow the steps below to use SpatialCOC and reproduce the results presented in our paper:

1. **Set up the environment and download the data**
   Follow `./Installation.ipynb` and `./Tutorials/Data_Preparation.ipynb` to configure the environment and prepare the data.
2. **Run the tutorials**
   Execute the tutorials in `./Tutorials/Tutorial_[1-5].ipynb` sequentially.
3. **Reproduce the results**
   Follow the instructions in the `./Results` subfolder to reproduce the results reported in the paper.
